# MobileNet-CIFAR10-Image-Classification

## Objective
The objective of this project is to build a lightweight image classification model using MobileNet and evaluate its performance on the CIFAR-10 dataset.

---

## Dataset
CIFAR-10 is a dataset that contains 60,000 images divided into 10 different classes:
- Airplane
- Automobile
- Bird
- Cat
- Deer
- Dog
- Frog
- Horse
- Ship
- Truck

---

## Methodology
1. Load the CIFAR-10 dataset
2. Normalize the image data
3. Build the MobileNetV2 model
4. Train the model using training data
5. Evaluate the model using test data

---

## Technologies Used
- Python
- TensorFlow
- Keras
- Google Colab

---

## Results
The model achieves approximately:
- Training Accuracy: ~85%
- Testing Accuracy: ~80%
